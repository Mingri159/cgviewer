# cgviewer
CGViewer是一款面向CG插画收藏者的本地图片浏览器，专注于大规模CG图片的智能分组与高效预览。通过pHash感知哈希算法自动识别相似图片，将文件夹或压缩包的同场景、同角色的CG作品归为一组，解决手动整理的痛点。

# 核心功能

## 智能分组
pHash感知哈希：基于DCT离散余弦变换提取图像64-bit特征指纹，通过汉明距离衡量相似度
Union-Find聚类：阈值内的图片自动合并为同组，支持3-20档可调阈值
分组缓存：首次计算后缓存结果，相同目录再次打开秒级加载

## 图片浏览
流式布局：自适应窗口宽度，卡片自动换行居中排列
分组缩略图：封面图 + 红色角标显示组内数量
大图预览：滚轮鼠标锚点缩放、拖拽平移、←→方向键在全部图片间切换
分组网格：多图分组点击展开为网格视图，支持逐张预览

## 文件支持
文件夹加载：递归扫描目录，支持jpg/png/bmp/webp/gif/tiff
ZIP压缩包：直接读取ZIP内图片，无需解压
拖放操作：拖入文件夹或ZIP即可开始加载

## 其他
文件名搜索：实时过滤缩略图卡片
右键菜单：大图预览、复制到剪贴板
可配置：缩略图宽度、网格间距、分组列数、哈希阈值均可调

# 技术栈

## 组件	技术
语言	Python 3
GUI框架	PyQt6
图像处理	OpenCV + NumPy
哈希算法	pHash (DCT-based perceptual hash)
聚类算法	Union-Find (并查集)
布局	自定义FlowLayout (流式自适应)

## 界面风格

深色主题（#0e0e12背景），蓝紫色强调色（#6c8cff），圆角卡片设计，整体风格简洁克制。
